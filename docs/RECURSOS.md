# Recursos gráficos

La versión original actualizada del equipo incorporó 48 imágenes a `Proyecto/img/`. En este repositorio se sincronizaron y comprobaron **44 imágenes**. Los siguientes cuatro archivos permanecen pendientes, porque su transferencia como contenido binario grande no se completó:

- `Proyecto/img/4K WALKPAPPER.jpg`
- `Proyecto/img/baño basico.png`
- `Proyecto/img/pagos.png`
- `Proyecto/img/stickernos.png`

Para completar la sincronización se pueden descargar esos cuatro archivos desde el [repositorio original](https://github.com/Andre1609/Peluquerias-Caninas/tree/master/Proyecto/img) y copiarlos en la misma carpeta `Proyecto/img/` de esta copia, conservando exactamente sus nombres. Confirmar con el equipo que el uso de las imágenes es apropiado para un repositorio público.
