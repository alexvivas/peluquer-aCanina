# Limitaciones y mejoras pendientes

## Funciones implementadas

- Navegación por páginas HTML y estilos CSS separados por secciones.
- Carrito de compras local con `localStorage`, cantidades y cálculo de totales.
- Búsqueda y filtrado de productos mediante JavaScript y DOM.
- Preferencia de tema claro y oscuro guardada en el navegador.
- Validación de formulario de reclamaciones del lado del cliente.

## Limitaciones actuales

- **Sin backend ni base de datos:** no se registran transacciones o reclamaciones reales.
- **Cuatro imágenes grandes pendientes:** revisar [`RECURSOS.md`](RECURSOS.md).
- Enlaces comerciales y datos de terceros desactivados o sustituidos para la versión pública.
- No hay pruebas automatizadas ni una verificación visual completa documentada.
- Es un prototipo académico, no un sistema de e-commerce listo para producción.

## Mejoras recomendadas

1. Completar las cuatro imágenes pendientes con autorización del equipo.
2. Verificar navegación, carrito, búsqueda y tema oscuro en navegador de escritorio y móvil.
3. Revisar accesibilidad de botones, imágenes y formularios.
4. Documentar las responsabilidades de cada integrante.
5. Considerar una demo estática en GitHub Pages una vez verificadas las rutas y los recursos.
